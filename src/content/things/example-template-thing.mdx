This is the body of a Thing. It's plain Markdown (or MDX), so headings,
paragraphs, links, code and images all work as usual.

## A small Thing can be this short

A single cover photo, a title, a date and two sentences is a complete Thing.
Not every project needs sections, galleries or a long write-up.

## A bigger Thing can have more

Bigger Things can include several sections, more photos, and things like
code blocks:

```ts
const thing = {
  title: "Hand-wired keyboard",
  madeWith: ["Raspberry Pi Pico", "diodes", "patience"],
};
```

Or a gallery of extra photos declared in the frontmatter above — see the
images at the bottom of this page.

> leave it here as a reference — it never shows up on the homepage or on
> `/things` because `example: true` filters it out of both listings.
